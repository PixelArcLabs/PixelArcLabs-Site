# Pixel Arc Labs Site

A modern one-page company site for [pixelarclabs.com](https://pixelarclabs.com), built with Astro and Tailwind CSS.

## Pages

| URL | Purpose |
|-----|---------|
| `/` | Company landing page with support contact |
| `/privacy` | Generic Pixel Arc Labs privacy policy |

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Build

```bash
npm run build
npm run preview
```

Static output is written to `dist/`.

## Deploy to Netlify

See the step-by-step deploy guide in the project docs, or follow Netlify's "Import from Git" flow. Build settings are in `netlify.toml` (`npm run build`, publish `dist/`).
